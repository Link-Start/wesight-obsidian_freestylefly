# WeSight for Obsidian 1.2.0

新增 Claude Code 的 OpenLux 接入，模型按 OpenAI、Google、Anthropic、DeepSeek 等原厂分类，聊天选择器采用左右两栏布局。

## OpenLux 接入

- 在设置 → Claude → 自定义配置中选择 OpenLux，供应商排列在 TokenDance 后。默认地址为 `https://api.openlux.ai/v1`，通过个人 API Key 连接。
- 提供官网、文档、测试连接和获取账户模型列表入口；初始目录为空，可手动添加、编辑、删除模型。
- 设置页支持独立默认模型选择、名称与 ID 搜索、可折叠厂商分组、图标、数量和默认标记。
- 已知模型系列优先于接口的统一厂商标签，完整模型 ID 原样发送；自动过滤专用图片生成、视频、语音、嵌入和重排模型。
- 刷新保留自定义名称和手动模型，失败保留当前目录；图片输入标记依据明确能力数据显示。

## 聊天与兼容性

- Claude 自定义配置的聊天选择器左侧选择供应商，右侧显示模型；OpenLux 支持厂商分组，其他供应商保留普通模型列表。
- 选中 OpenLux 模型后显示模型名称与“OpenLux · 厂商”。弹层适配窄侧栏，支持键盘操作、Escape、外部点击关闭及焦点恢复。
- 本机代理支持文本、图片、工具调用及流式和非流式响应，每轮使用独立临时令牌，真实密钥保留在插件进程与 Obsidian SecretStorage。
- 配置新增可选模型目录元数据，保留旧模型列表与默认模型字段；旧配置无需迁移，导入导出默认脱敏。
- TokenDance、会员模型、Codex、本机 Claude 和 OpenCode 的现有流程继续兼容。

- `npm run check` 通过：483 项测试通过，1 项可选测试跳过；lint 无错误，类型检查、构建和发布资源校验通过。
- 已检查 Obsidian 明暗主题、窄侧栏及键盘操作；OpenLux 模拟目录另验证分组、完整 ID 选择与默认模型保存恢复。
