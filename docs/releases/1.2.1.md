# WeSight for Obsidian 1.2.1

发布日期：2026-10-02。

修复 Claude Code 在 Chat 对话中完成回复后，正文和思考内容重复追加的问题。

## 修复

- Claude 同时返回流式片段和完整消息时，已显示的内容只保留一次；完整消息只补充尚未收到的文字。
- 支持同一消息分段返回完整内容，保留正常的重复词句、空白和后续消息。
- 每轮对话使用独立解析状态，避免不同对话和连续请求互相影响。

## 升级与验证

- 最低支持桌面版 Obsidian 1.11.4。手动更新使用本 Release 的 `main.js`、`manifest.json`、`styles.css`，更新后关闭再开启 WeSight 或重启 Obsidian。
- 使用新回复验证：选择 Claude Code，发送问题，等待回复结束，确认正文没有再次重复追加。历史消息中已保存的重复内容不会自动清理。
- 新增 7 项回归测试，覆盖流式片段与完整消息、思考内容、遗漏片段补全、分段完整消息、正常重复内容、独立解析器及连续运行。
- 隔离运行时探测测试与开发者本机安装的 OpenCode，确保“未安装”场景可稳定验证。
- `npm run check` 通过：490 项测试通过，1 项可选测试跳过；lint 无错误，类型检查、构建和发布资源校验通过。
