# WeSight for Obsidian 1.1.0

新增 Claude Code 会员模型与 TokenDance 接入，把额度查询集中到头像菜单和网页使用情况页，让聊天区更简洁。

## 会员模型与 TokenDance

- Claude Code 新增“默认配置（推荐）”，可使用账户已开放的 WeSight 会员模型，无需填写模型 API Key。
- 支持模型切换、会员状态检查、独立周额度和恢复时间；实际可用模型与权益以账户实时状态为准。
- 首次使用会员模型会说明消息、选中文件上下文和工具结果的发送范围。取消确认、权益不足或连接失败时保留输入内容。
- 未安装 Claude Code 时提供官方安装入口；已有安装优先复用。已有用户的引擎与配置来源保持原选择。
- 自定义配置新增 TokenDance 浏览器授权、模型目录、连接测试及断开连接，支持原生 Messages 和兼容协议模型。

## 使用情况

- 头像下拉菜单在“检查更新”下方新增“使用情况”，右侧显示灰色“剩余 xx%”，打开菜单自动刷新额度。
- 点击进入网页使用情况页，查看周剩余额度、恢复时间、各模型成功调用及占用额度、最近调用记录。
- 聊天区在运行环境和会员权益就绪后隐藏使用准备卡，模型统一在输入框下方选择，显示模型名称和当前选择状态。
- 聊天与公众号预览共用额度入口，并修正头像菜单的位置；网页端页面与接口已发布，修复入口打开 404 的问题。

## 其他改进

- 发布助手安装说明补充 Arc 浏览器，优化多平台草稿交接提示。
- 网页账户详情展示各功能的积分消费记录，完善功能名称与记录标题。
- 改善分享文章长标题在桌面端的排版，保留移动端换行。

## 升级说明

- 最低支持桌面版 Obsidian 1.11.4。手动更新使用本 Release 的 `main.js`、`manifest.json`、`styles.css`，更新后重新加载插件。
- 会员模型的周额度独立于账户积分；不会自动扣积分或切换到个人 API 配置。模型开放范围遵循账户实际权益。
- TokenDance 个人授权使用该服务的个人账户额度，与 WeSight 会员额度分别管理。
